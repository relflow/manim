# Animation assets

The RelFlow logo and Libertinus Serif wordmark face were retained from the
original explainer branch. `OFL.txt` contains the Libertinus license.

Body text and code use Noto Sans and Noto Sans Mono, bundled from the Google
Fonts repository so the renderer can use the same fonts across platforms:

- [Noto Sans](https://github.com/google/fonts/tree/main/ofl/notosans),
  with its license in `notosans-OFL.txt`.
- [Noto Sans Mono](https://github.com/google/fonts/tree/main/ofl/notosansmono),
  with its license in `notosansmono-OFL.txt`.

The font files retain the SIL Open Font License. Their SHA256 fingerprints are
recorded in `archive/checksums.sha256` and every rendered segment's provenance.
